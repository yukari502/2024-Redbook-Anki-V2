# 2024-Redbook-Anki-V2
本卡组是基于牌组 2024红宝书考研词汇（必考词+基础词+超纲词）（原作者链接https://ankiweb.net/shared/info/75315103） 重构的 V2 版。
由于原作者已停止维护，且原卡组中存在大量发音音频损坏、缺失的问题，动画效果也略显冗余。为了获得更高效、更专注的体验，我经过数十天的实际使用和我个人的使用习惯，对全牌组的底层代码和内容进行了修改和补充。

修改的目的是补充：损坏音频、精简动画效果、精简牌组冗余内容，让体验更加干净简练。

主要改动如下：

1. 发音音频全面修复与补全：
清理了原卡组中失效的音频链接，为了保证发音的一致性，将原有的音频全部利用微软云Azure语音服务进行了重构（约6000条）

2. UI 动效极简优化与排版升级：
删除了原本点击时复杂的翻转、延迟和高耗能的过渡动画，让整体更加简洁。
去除了原先边栏和例句模块多余的边框和阴影，采用更现代的扁平化无框设计。
优化了 HTML/CSS，引入了 M PLUS 1 Code 等等宽字体，重新规划了行距与字号，长时间背诵也能保持眼部舒适，并适配 Night Mode（夜间模式）。

3. 单元层级重新排布：
现将所有词汇重新规整，仅以重要程度作为区分标准，精简合并为 A 基础1、B 基础2、C 进阶 三大模块，让复习规划更直观。

4. 冗余字段清理：
根据我个人的使用习惯，删除了原卡组中实际利用率极低、容易分散注意力的栏目。让卡片回归“单词-释义-例句”学习闭环。

5. 单词释义更新
原卡组同时并存了“红宝书原书释义”与“牛津词典释义”，导致卡片内容极度臃肿。经过比对和一段时间的使用，本版本删除了原书释义，仅保留质量更高的牛津释义，并将其作为主要释义使用，一定程度上轻量化了卡组内容。
